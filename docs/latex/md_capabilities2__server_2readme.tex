 Capabilities2 server allows interaction with the capabilities2 API. It is a reimplementation of the capabilities package using C++ (original capabilities package was written in Python 2.\+7). In addition to C++ reimplementation being more resource efficient, this package extends the capabilities package features in following ways,


\begin{DoxyEnumerate}
\item Database support for storing capabilities.
\item Capability registration through service calls.
\item Abstracted providers through a {\itshape runners} API see \doxysectlink{md_capabilities2__runner_2readme}{capabilities2\+\_\+runner}{0}
\end{DoxyEnumerate}\hypertarget{md_capabilities2__server_2readme_autotoc_md49}{}\doxysection{\texorpdfstring{Specialising the capabilities2 server}{Specialising the capabilities2 server}}\label{md_capabilities2__server_2readme_autotoc_md49}
The capabilities2 server is implemented as a \href{https://docs.ros.org/en/jazzy/Concepts/Intermediate/About-Composition.html}{\texttt{ ROS2 Component}}. The server can be specialised by composing it with another Component that adds domain logic.\hypertarget{md_capabilities2__server_2readme_autotoc_md50}{}\doxysection{\texorpdfstring{Launch capabilities2 server}{Launch capabilities2 server}}\label{md_capabilities2__server_2readme_autotoc_md50}
