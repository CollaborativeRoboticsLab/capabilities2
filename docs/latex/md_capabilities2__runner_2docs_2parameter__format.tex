Runners can use parameters. These parameters are passed to the runner in the {\ttfamily trigger} function. The parameter format for capabilities2 uses XML. A runner expects to receive a minimal XML structure which includes an ID attribute, for example\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{<\textcolor{keywordtype}{parameters}\ \textcolor{keyword}{id}=\textcolor{stringliteral}{"{}1234"{}}>}

\end{DoxyCode}


The {\ttfamily id} is used to identify the runner instance and manage its execution.
