 Capabilities features can be tested using the provided test scripts. The test scripts primarily test the capabilities2 server using service clients. Launch the capabilities2 server before running the test scripts using


\begin{DoxyCode}{0}
\DoxyCodeLine{source\ install/setup.bash}
\DoxyCodeLine{ros2\ launch\ capabilities2\_server\ capabilities2\_server.launch.py}

\end{DoxyCode}


The test scripts are written to test against the {\ttfamily std\+\_\+capabilities} package. Make sure that the {\ttfamily std\+\_\+capabilities} package is copied along with the {\ttfamily capabilities2} package to the {\ttfamily capabilities2\+\_\+ws/src} folder and is built and sourced before running the test scripts.

\begin{quote}
{\bfseries{Note}}\+: The test scripts use the {\ttfamily bondpy} package. Make sure it is installed before running the test scripts. \textbackslash{} {\ttfamily sudo apt install ros-\/\$ROS\+\_\+\+DISTRO-\/bondpy} \end{quote}
Run the tests with python3. The test scripts are located in the {\ttfamily capabilities2\+\_\+server/test} directory. Make sure to source the workspace before running the test.


\begin{DoxyCode}{0}
\DoxyCodeLine{\#\ example}
\DoxyCodeLine{source\ install/setup.bash}
\DoxyCodeLine{cd\ src/capabilities2/capabilities2\_server/test}
\DoxyCodeLine{python3\ call\_establish\_bond.py}

\end{DoxyCode}
