\hypertarget{md_docs_2setup__with__dev_autotoc_md105}{}\doxysubsection{\texorpdfstring{Devcontainer}{Devcontainer}}\label{md_docs_2setup__with__dev_autotoc_md105}
A {\ttfamily devcontainer} is provided for developing the capabilities2 meta-\/package. The container can be used with \href{https://code.visualstudio.com/}{\texttt{ Microsoft Visual Studio Code}} and \href{https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.vscode-remote-extensionpack}{\texttt{ Remote Development Extention}}.

If there are multiple packages in the workspace as with the usual case, move the {\ttfamily .devcontainer} folder into the parent folder such that it is located as follows,


\begin{DoxyCode}{0}
\DoxyCodeLine{colcon\_ws}
\DoxyCodeLine{-\/-\/>\ build}
\DoxyCodeLine{-\/-\/>\ install}
\DoxyCodeLine{-\/-\/>\ log}
\DoxyCodeLine{-\/-\/>\ src}
\DoxyCodeLine{\ \ \ \ -\/-\/>\ .devcontainer}
\DoxyCodeLine{\ \ \ \ -\/-\/>\ capabilities2}
\DoxyCodeLine{\ \ \ \ -\/-\/>\ pakcage\ ..}

\end{DoxyCode}


Close and reopen the vs code editor so that devcontainer is automatically detected. After that, Dependencies need to be installed in the container. Install the dependencies with rosdep\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{\#\ in\ the\ devcontainer}
\DoxyCodeLine{rosdep\ install\ -\/-\/from-\/paths\ src\ -\/-\/ignore-\/src\ -\/r\ -\/y}

\end{DoxyCode}
