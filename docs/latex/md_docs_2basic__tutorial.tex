 This tutorial will guide you through the basic steps of using {\ttfamily capabilities2}. It will cover the following topics\+:


\begin{DoxyEnumerate}
\item Creating a capability using yaml model files.
\item Run the capabilities server to serve the capability.
\item Run the capabilities runner to execute the capability.
\end{DoxyEnumerate}

The tutorial will create a simple capability that prints "{}\+Hello, World!"{} to the console, using talker-\/listener nodes as a backend sub-\/system.

The capabilities server will serve the capability, and then spawn a runner that will execute the capability.\hypertarget{md_docs_2basic__tutorial_autotoc_md61}{}\doxysection{\texorpdfstring{Creating a capability}{Creating a capability}}\label{md_docs_2basic__tutorial_autotoc_md61}
