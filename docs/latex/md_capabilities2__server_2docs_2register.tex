 Capabilities can be registered by exporting them in a package. The capabilities2 server will read the capabilities from the package and make them available to the user. Basic capability use case needs two components to be registered; {\ttfamily capability\+\_\+interface} and {\ttfamily capability\+\_\+provider}. Optionally, a third component can be added as {\ttfamily semantic\+\_\+capability\+\_\+interface}.

Capabilities can also be registered through a service call. This is useful for registering capabilities that are not exported in a package. The service call has been implemented as a node in the capabilities2 package. Use the node to register capabilities during runtime. This method can also be used to update capabilities.
